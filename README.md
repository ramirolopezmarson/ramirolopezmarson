### 🔫 [Manual of Arms](https://drasombroso.itch.io/manual-of-arms)

A first-person bolt-action rifle you operate by hand. You grab the handle and drag it along the path
it actually travels — lift, pull, push, lower — and the gun stops wherever you stopped.

There is no short-stroke detection anywhere in the codebase. There doesn't need to be: pull the bolt
to 0.9 and push it home and you've crossed the ejection threshold but not the cocking one, so the
case flies and the striker stays down. The failure is a position you didn't reach.

Built in Blueprint, playtested, found to be wrong in a way I couldn't see from the inside, rebuilt
from phases into positions, then ported to C++ against the frozen original so the two could be
compared directly.
